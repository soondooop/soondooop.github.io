업무 체크

오늘의 할 일을 차분히 남깁니다. 목록은 비공개 GitHub 저장소에만 저장되고, 이 페이지 저장소에는 올라가지 않습니다.

토큰 만드는 방법

  1. Fine-grained token 만들기로 이동합니다. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token 입니다.
  2. Repository access는 Only select repositories로 두고, 데이터를 둘 저장소만 선택합니다. 기본값은 비공개 저장소 soondooop/todo-data 입니다.
  3. Repository permissions에서 Contents만 Read and write로 설정합니다. 다른 권한은 필요 없습니다.
  4. 발급한 토큰(github_pat_…)을 위에 붙여 넣습니다.

soondooop.github.io는 공개 저장소입니다. 할 일 JSON을 이 사이트 저장소에 저장하지 마세요. 토큰은 이 브라우저에만 남고, 페이지 소스나 커밋에는 포함되지 않습니다.
