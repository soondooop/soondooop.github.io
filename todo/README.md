# 업무 체크

오늘의 할 일을 정리하는 개인용 목록입니다. 빌드 없이 `index.html`만으로 동작하며, GitHub Pages에서 [https://soondooop.github.io/todo/](https://soondooop.github.io/todo/) 로 열립니다.

데이터는 이 공개 저장소에 저장하지 않습니다. 기본 위치는 비공개 저장소 **soondooop/todo-data** 의 `main` 브랜치, `todos.json` 입니다.

## 로그인

Fine-grained personal access token으로 로그인합니다.

1. [Fine-grained token 만들기](https://github.com/settings/personal-access-tokens/new)로 이동합니다.
2. Repository access는 **Only select repositories**로 두고, 데이터를 둘 저장소만 선택합니다.
3. Repository permissions에서 **Contents**만 **Read and write**로 설정합니다.
4. 발급된 토큰을 로그인 화면에 붙여 넣습니다.

「이 기기에서 로그인 유지」를 켜면 토큰을 이 브라우저의 `localStorage`에 둡니다. 끄면 탭 세션 동안만 유지합니다. 로그아웃하면 토큰을 지웁니다. 토큰은 페이지 저장소에 커밋되거나 로그로 남지 않습니다.

## 저장

GitHub Contents API로 파일을 읽고 씁니다. 파일이 없으면 처음 저장할 때 만듭니다.

- 변경 후 약 1.5초 뒤 자동 저장됩니다. **저장** 버튼은 바로 올리고, 변경이 없으면 원격과 다시 맞춥니다.
- 커밋 메시지 형식은 `todo: update 2026-11-13 09:31` (서울 시각) 입니다.
- 상태 표시: **저장됨**, **저장 중**, **오프라인**, **충돌**. 권한 오류는 **오류**로 표시됩니다.
- 같은 할 일 id가 겹치면 `updatedAt`이 더 새로운 쪽을 남깁니다. 이 기기에서 지운 항목은 그 시각보다 오래된 원격 복사본보다 우선합니다.
- 네트워크가 끊기면 이 브라우저에 임시로 남겨 두었다가, 다시 연결되면 저장합니다.

설정에서 소유자, 저장소, 브랜치, 경로를 바꿀 수 있습니다. 데이터 저장소는 **Private**으로 유지하세요.

## 기능

- **오늘**, **백로그**, **완료**. 체크한 할 일은 그 목록에 남고, 덜 끝난 일 아래에 모입니다. 제목에 취소선이 생기고 `완료 10:42`처럼 시각이 붙습니다. 다시 체크를 풀면 원래대로 돌아옵니다.
- **완료 항목 숨기기**는 오늘과 백로그에서 완료 행만 가립니다. 기본은 보이기이고, 선택은 이 기기에 남습니다.
- **완료** 화면은 날짜별로 묶인 기록입니다. 어제 끝낸 오늘 할 일은 다음 날 오늘 목록에서는 빠지고, 여기서 그대로 볼 수 있습니다. 데이터는 지우지 않습니다.
- 빠른 추가, 더블 클릭 또는 Enter로 제목 수정, 완료, 삭제 후 실행 취소.
- 오늘과 백로그 안에서 끌어서 또는 키보드로 순서를 바꿉니다. 필터 중에는 순서를 바꿀 수 없습니다.
- `T` / `B` 또는 더보기 메뉴로 오늘과 백로그를 옮깁니다.
- 우선순위 높음 / 보통 / 낮음. 기한이 지난 할 일은 날짜를 강조합니다.
- 빠른 추가의 `#태그`, `!높음` `!보통` `!낮음`, `YYYY-MM-DD`는 제목에서 빠져 태그, 우선순위, 기한이 됩니다.
- 태그 칩을 누르면 그 태그만 봅니다.
- 오늘 진행률과 서울 기준 오늘 날짜를 헤더에 보여 줍니다.
- 할 일마다 짧은 메모를 펼칠 수 있습니다.
- 끝나지 않은 오늘 할 일은 날짜가 바뀌면 다음 날로 넘어갑니다. **이월** 배지에 넘어온 일수를 더합니다. 전날 완료한 일은 오늘 목록에서 빠지고 완료 기록에 남습니다.
- **예정** 달력은 일요일부터 시작하고, 일요일과 대한민국 공휴일은 빨강, 토요일은 파랑으로 보여 줍니다. 공휴일 이름이 칸에 함께 나옵니다. 해야 할 일과 완료도 같이 보여 줍니다. 기한이 있는 일은 그 날짜에, 기한 없는 오늘 할 일은 오늘에, 이월·기한 지난 일은 원래 날짜와 오늘에 빨간 표시로 나옵니다. 칸에는 제목을 대략 세 줄까지 보여주고 나머지는 `+N개 더`입니다. 하루를 누르면 해야 할 일과 완료를 나누어 완료 체크, 편집, 그 날짜로 추가할 수 있습니다. 좁은 화면의 칸은 개수와 점만 보여 줍니다. `모두` / `할 일 보기` / `완료 보기`로 거를 수 있습니다.
- 기한은 날짜와 시간을 함께 둘 수 있습니다. 빠른 추가는 `내일`, `모레`, `금요일`, `11/20`, `오후 3시`를 이해합니다. 지난 기한은 강조됩니다.
- **반복**은 매일, 평일, 매주(요일 선택), 매월(말일 포함), 매년, N일입니다. 완료하면 다음 회차가 생기고, 끝낸 회차는 기록으로 남습니다. 회차 id는 `seriesId@날짜`라 두 기기에서 동시에 저장해도 중복되지 않습니다.
- **카테고리**는 태그와 별개입니다. `@회의`처럼 빠르게 붙일 수 있고, 색과 이름을 바꿀 수 있습니다. 목록은 카테고리, 우선순위, 기한, 생성일, 수동 순서로 정렬하고 카테고리로 묶을 수 있습니다. 정렬과 묶기는 이 기기에 남습니다.
- 제목이나 메모가 한 줄을 넘치면 **더보기**가 나타납니다. 누르면 줄바꿈된 전체 내용이 보이고, **접기**로 돌아갑니다.
- **알림**은 브라우저 알림입니다. 기한 시각, 선택한 미리 알림, 아침 브리핑을 이 탭이나 설치한 앱이 켜져 있을 때만 띄웁니다. 푸시 서버는 없습니다. 기한이 지난 개수는 탭 제목에 표시됩니다.
- JSON 내보내기와 가져오기. 가져올 때는 병합 또는 교체를 고릅니다.
- 테마는 시스템을 따르고, 라이트 / 다크로 바꿀 수 있습니다. 선택은 이 기기에 남습니다.

## 단축키

입력란에 커서가 있을 때는 동작하지 않습니다. 한글 입력기에서는 영문 입력 상태에서 사용해 주세요.

| 키 | 동작 |
| --- | --- |
| `N` | 새 할 일 |
| `/` | 검색 |
| `Enter` | 선택한 행 편집, 편집 저장 |
| `Esc` | 취소, 닫기 |
| `J` / `K` | 아래 / 위 항목으로 이동 |
| `X` 또는 `Space` | 완료 토글 |
| `1` / `2` / `3` | 우선순위 높음 / 보통 / 낮음 |
| `T` / `B` | 오늘 / 백로그로 이동 |
| `C` | 예정 |
| `D` | 기한 |
| `R` | 반복 |
| `Alt+↑` / `Alt+↓` | 순서 변경 (`Alt+J` / `Alt+K`) |
| `Delete` | 삭제 (실행 취소 가능) |
| `?` | 단축키 도움말 |

## JSON

버전 1 파일도 그대로 열립니다. 저장하면 버전 2가 되고, 없던 필드는 비워 둡니다.

```json
{
  "version": 2,
  "updatedAt": "2026-11-13T00:31:00.000Z",
  "rolloverDate": "2026-11-13",
  "categories": [{ "id": "cat-meeting", "name": "회의", "color": "blue" }],
  "tasks": [
    {
      "id": "7d6a…",
      "title": "제안서 초안 검토",
      "memo": "",
      "priority": "high",
      "due": "2026-11-13",
      "tags": ["제안"],
      "list": "today",
      "status": "open",
      "order": 0,
      "createdAt": "2026-11-12T01:00:00.000Z",
      "updatedAt": "2026-11-13T00:31:00.000Z",
      "completedAt": null,
      "carriedDays": 1
    }
  ]
}
```

- `priority`: `high` | `medium` | `low`
- `list`: `today` | `backlog`
- `status`: `open` | `done`
- `due`: `YYYY-MM-DD` 또는 `null`. `dueTime`은 `HH:MM` 또는 `null`
- `categoryId`: `categories`의 id 또는 `null`
- `repeat`: `null` 또는 `{ freq, interval, weekdays, monthDay }`. `seriesId`와 `occurrenceDate`는 반복 회차를 구분합니다
- `reminder`: `null` | `at` | `10m` | `30m` | `1h` | `1d9`
- `rolloverDate`: 마지막으로 이월을 적용한 날짜입니다. 기기마다 다르게 세지 않도록 파일에 둡니다.

`rolloverDate`가 없으면 처음 열 때 오늘을 기준일로만 잡고, 그날은 이월하지 않습니다.
