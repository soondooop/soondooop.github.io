# Kim Seungdo — Portfolio

웹 퍼블리셔 / 프론트엔드 포트폴리오입니다.  
이 저장소는 GitHub Pages 배포본이며, 앱 소스는 별도 레포에서 관리합니다.

## Live

- Site: https://soondooop.github.io/
- Play mode: https://soondooop.github.io/play
- Interior Proposal Studio: https://soondooop.github.io/interior-proposal/

## Features

- Classic portfolio UI (Overview / Experience / Skills / Projects / Contact)
- Dot RPG style exploration mode (`/play`)
- Club Desk demo admin (`/club-desk`)
- Interior Proposal Studio demo

## Tech Stack

- React, TypeScript, Vite
- Phaser (Play mode)
- Redux Toolkit + Axios (Club Desk)
- GitHub Pages
- Google Analytics 4

## Repository Structure

- `data/` — 포트폴리오·프로젝트 콘텐츠 (JSON)
- `interior-proposal/` — 인테리어 제안 스튜디오 데모
- `assets/`, `index.html` — 사이트 빌드 산출물
- `ogimage/` — 프로젝트 썸네일·OG 이미지

## Content

프로필·프로젝트 목록은 JSON으로 관리합니다.  
파일만 수정한 뒤 이 저장소에 push하면 사이트 내용이 갱신됩니다.

- [`data/portfolio.json`](./data/portfolio.json)
- [`data/projects.json`](./data/projects.json)
